# Contributing to Project Far Far Away

Keep changes focused and describe the problem, the resulting behavior, and the checks you actually ran. Label AI-assisted contributions and review their output before submission.

For gameplay bugs, include the level or bonus game, selected heroes, relevant QoL settings, device and Android version, build version, reproduction steps, and an original-game comparison when available. Separate observed behavior from assumptions.

Never commit ROMs, player saves, signing keys, local SDK/JDK installations, or compiled APKs. Keep the exact-ROM import requirement intact. Do not change the Android application ID merely to rename the project.

Project code contributions are submitted under GNU GPL v3.0, the same license as the project. Preserve applicable copyright and license notices. The project license does not grant rights to original game assets or other third-party material.
